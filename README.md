# Spring Blockchain Monit

A Spring Boot application for blockchain monitoring.

## Features

- Spring Boot backend with Gradle build system
- Node.js frontend integration
- Docker support for containerized deployment
- Automated CI/CD with GitHub Actions

## Getting Started

### Prerequisites

- Java 11 or higher
- Gradle 7.4.2 or higher
- Node.js 16.x or higher
- Docker (optional, for containerized deployment)

### Building the Application

```bash
cd BlockchainMonit
./gradlew build
```

### Running the Application

```bash
cd BlockchainMonit
./gradlew bootRun
```

The application will start on http://localhost:8080

## Docker

This project includes Docker support for easy deployment. See [DOCKER.md](DOCKER.md) for detailed instructions.

### Quick Start with Docker

```bash
docker pull fyhao/springblockchainmonit:latest
docker run -p 8080:8080 fyhao/springblockchainmonit:latest
```

## Development

### Running Tests

```bash
cd BlockchainMonit
./gradlew test
```

### Frontend Development

```bash
cd BlockchainMonit
npm install
npm test
```

## CI/CD

The project uses GitHub Actions for continuous integration and deployment:

- **Gradle Build:** Validates Java code, runs tests, and generates reports
- **Node.js CI:** Tests Node.js components across multiple versions
- **Docker Build:** Automatically builds and pushes Docker images to Docker Hub
- **CodeQL Analysis:** Security scanning

## Docker Hub

Docker images are automatically published to:
